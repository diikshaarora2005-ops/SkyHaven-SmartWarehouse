# SkyHaven Smart Warehouse Management System

A full-stack Smart Warehouse Management System built using Spring Boot, React.js, MySQL, and JWT Authentication with advanced admin controls, real-time notifications, automated reporting, invoice generation, and customer order tracking.

---

* JWT-based Authentication System
* Role-Based Access Control
* Smart Session Security & Auto Re-Authentication System
* Secure Admin/User Separation
